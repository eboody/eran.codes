# Group

- Route: `/docs/group`
- Category: Components
- Source: `app/routes/docs.group.jsx`

Stack forms elements and buttons horizontally with role='group' and role='search'.

## Key Sections
- Forms
- Search
- Buttons

## Example Snippets

<form>

</form>
